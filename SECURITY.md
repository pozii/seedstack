# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

Seedstack is pre-1.0, so fixes land on the main branch and ship with the next tagged release.

## Reporting a vulnerability

Open a private security advisory on the GitHub repository with a description, reproduction steps, and the affected commit or version. Expect an acknowledgement within three days and a fix or a mitigation plan within two weeks for confirmed issues.

Please do not open public issues for vulnerabilities. Dependency reports from automated tooling are welcome as pull requests bumping the lockfile.
